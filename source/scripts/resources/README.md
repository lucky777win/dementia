# 照護資源地點資料處理

產出 `src/data/resources.json`（以及 `data/照護資源地點清冊.csv` 供人工覆核）。

1. `build_res.py`：讀取三份官方清冊（共照中心 .ods／.pdf、失智據點與團體家屋 .pdf）。共照中心 .ods 與 .pdf 會互相比對。
2. `norm.py`：地址正規化（全形半形、臺／台、去除村里與鄰、段與門牌數字寫法統一），作為比對同一地點的依據。
3. `merge.py`：臺中市改用衛生局 115-09-30 資源表；其他縣市用全國清冊。同一地址的服務合併成一個地點。
4. `centroids.cjs`：用 taiwan-atlas（內政部村里界）計算村里與鄉鎮市區的中心點，作為地圖的約略座標。
5. `county_info.json`：各縣市失智照護服務網頁與聯絡窗口。

座標不是門牌定位。若取得正式的門牌座標（例如 TGOS 門牌定位服務），可直接替換 resources.json 中的 lat／lng，並把 pr 改成 'a'。
