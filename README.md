# 憶起照顧｜失智關懷與資源整合平台（原型）

從理解開始，讓照顧不再孤單。陪伴您認識失智症、了解照護方式，找到需要的資源與支持。

- 網站：<https://lucky777win.github.io/dementia/>
- 內容取自「憶起照顧雛型」：照顧文章與導航規則**尚未經專家與個管師覆核**，頁面上皆有標示。
- 據點資料：臺中市政府衛生局「115 臺中市失智照護服務資源表」（115 年 9 月 30 日版）。
- 本頁為單一檔案（index.html），由 React + TypeScript + Tailwind CSS 原始碼建置；更新時以新的 index.html 覆蓋即可。
